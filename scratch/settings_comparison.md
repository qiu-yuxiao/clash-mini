# Clash WinAero 现存代码与最新协议文字记录比对结果

本报告对比了当前工作区 `AntiGravity_Projects\ClashVerge` 中的实际代码与《权威开发协议》(clash_winaero_agreements.md)、《避坑红线》(clash_winaero_pitfalls.md) 以及《记忆归档》(clash_winaero_memory.md) 中的最新文字要求，整理出以下所有差异项：

## 1. 设置侧边栏抽屉与布局差异 (`src/pages/_layout.tsx` 对齐协议)
*   **最新协议要求**：
    1. 下半层固定高度为 **`178px`**（恢复原版 130px 折线图物理高度，防止时间轴与 "Smooth/Points" 重叠）。
    2. 设置抽屉采用 100% 实体纯色不透明背景，亮色 `#f0f5ff`，暗色 `#1e2438`，**彻底移除 `backdrop-filter` 虚化滤镜**。
    3. 设置抽屉子窗口的边缘采用 **`4px double`** 双实线设计（`border: "4px double var(--aero-border)"`）。
    4. 左侧设置分栏固定为 **`200px`** 宽度，右侧连接审计分栏自适应拉伸（**`flex: 1`**）。
*   **当前代码现状（不符/落后处）**：
    1. 当前下半层高度被设置为了 `height: '196px'`（`_layout.tsx` 第944行）。
    2. 当前设置抽屉背景是带虚化半透明的：`background: mode === 'light' ? 'rgba(240, 245, 255, 0.88)' : 'rgba(22, 28, 48, 0.93)'`，且包含 `backdropFilter: 'blur(30px) saturate(180%)'`（`_layout.tsx` 第638-639行）。
    3. 当前抽屉组件完全没有设定 `border` 边框样式。
    4. 当前左右分栏宽度仍为百分比分配（左侧 `35%`，右侧 `65%`）。

## 2. 基础设置部分差异 (`src/pages/_layout.tsx` 对齐协议)
*   **最新协议要求**：
    1. 基础设置卡片重命名为 **“基础设置”**（去除“与自适应”）。
    2. 子项描述文字（如“开机自动启动”等）字号调大到 **`13.5px`**，端口输入字号调为 **`12px`**。
    3. 新增 **“外观主题”** 选项，右侧渲染 22px 高度的 Select 选择框，支持 “系统默认”(system)、“浅色模式”(light)、“深色模式”(dark) 三者切换，大小字号与“代理策略”完全对齐。
    4. 将“系统调试运行日志”按钮更改为 **Contained** 样式（高度 26px），且将其**移动并居中**放置在“基础设置”卡片的最下方。
*   **当前代码现状（不符/落后处）**：
    1. 卡片标题依然显示为旧的 `"基础与自适应设置"`（`_layout.tsx` 第767行）。
    2. 描述文字字号依然是 `10px`（`fontSize: '10px'`）；端口输入框字号为 `10px`（`fontSize: 10`）。
    3. 列表中完全没有“外观主题”下拉选择项。
    4. “系统调试运行日志”按钮目前处于左侧整列的最底部（使用了 `mt: 'auto'`），且样式是 `variant="outlined"`，并未移动到卡片内部居中。

## 3. Mixed Port 输入框组件细节差异 (`src/pages/_layout.tsx` 对齐协议)
*   **最新协议要求**：
    1. 描述标签名称由“混合监听端口”统一替换为英文术语 **`Mixed Port`**，字号为 **`12px`**。
    2. 端口输入框强制使用 **`text`** 类型（以隐藏浏览器原生数值增减小箭头），宽度设为 **`60px`**，输入字号为 **`11px`**。
*   **当前代码现状（不符/落后处）**：
    1. 标签依然是中文的 `"混合监听端口"`，且字号为 `10px`（`_layout.tsx` 第810行）。
    2. 输入框目前是 `type="number"`，宽度为 `45`，字号为 `10px`（`_layout.tsx` 第815-818行）。

## 4. 订阅链接输入框细节差异 (`src/pages/_layout.tsx` 对齐协议)
*   **最新协议要求**：
    1. 提示占位符（Placeholder）修正为 **`"填入订阅链接 (YAML)"`**（消除重复词“订阅订阅”）。
    2. 输入框高度设为 **`26px`**，与右侧“导入”按钮完全等高对齐。
*   **当前代码现状（不符/落后处）**：
    1. 提示词依然为带有重复拼写错误的 `"填入订阅订阅链接 (YAML)"`（`_layout.tsx` 第664行）。
    2. 输入框高度未指定为 26px 等高。

## 5. 连接审计中心滚动条与容器约束差异 (`src/pages/_layout.tsx` 和 `connection-table.tsx` 对齐协议)
*   **最新协议要求**：
    1. 右侧路径控制分栏 Box 容器必须设置 `minHeight: 0` 和 `overflow: "hidden"` 属性，防止表格伸长溢出而导致滚动失效。
    2. 连接表格右侧滚动条移除本地的隐藏覆盖，直接继承并使用与主界面全局一致的滚动条。
*   **当前代码现状（不符/落后处）**：
    1. 右侧分栏 Box 容器未设置 `minHeight: 0` 和 `overflow: 'hidden'` 导致在抽屉高度约束时可能滚动失效（`_layout.tsx` 第841行）。
    2. 表格滚动条目前在 `connection-table.tsx` 中被设置为了完全隐藏 (`scrollbarWidth: 'none'`, `&::-webkit-scrollbar: { display: 'none' }`)，这与协议中“移除本地覆盖、继承使用全局一致滚动条”冲突。
