### 问题记录
- **问题1**：`http.extraheader` 存储 Token 明码到 `.git/config` → **已清除**
- **问题2**：`Read` 工具读取 `github_token.txt`，Token 暴露在对话记录中 → **严重违规，已改正**
- **问题3**：Windows SChannel SSL 握手失败 → 配置 `http.sslBackend=openssl`
- **问题4**：`gh` CLI GraphQL API 不可达 → 改用 REST API + `HTTPS_PROXY`
- **问题5**：首次 CI 失败 — Rust 类型不匹配：`entry_lightweight_mode()` 返回 `bool` 但 `tray/mod.rs` 代码用 `match` 当 `Result` 处理 → 修正后重新 tag 发布
- **Token 安全**：后续所有操作使用 `export GITHUB_TOKEN=$(cat github_token.txt | tr -d '\n\r')` + `credential.helper='!f(){ echo username=oauth2; echo password=$GITHUB_TOKEN; };f'`，**Token 不明码出现在命令行或文件中**
