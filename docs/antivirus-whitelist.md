# 轻量模式防误杀指南（360 等安全软件处理说明）

> 本文与 Clash Mini 客户端顶栏「`?` 帮助菜单 → 🛡️ 轻量模式防误杀指南」弹窗（`AntivirusWhitelistDialog`）保持一致，供仓库及 Wiki 读者查阅。

## 一、为什么轻量模式会被误杀？

Clash Mini 在关闭主窗口进入**轻量模式**时，会销毁 WebView2 前端界面进程以释放内存，仅保留系统托盘图标与代理内核（`mini-mihomo.exe`）常驻后台维持不断网不断流与 15 秒健康监测。

部分国内安全软件（如 360 安全卫士性能引擎 `360perfoptm2.dll`）会在全局监控**「曾经打开过可见窗口、随后又关闭窗口」**的后台程序，一旦机器出现持续高 CPU 负载，便会将其判定为“关窗残留进程”并强行终止。

> ⚠️ **注意**：经实机逆向分析与压测验证，360 的普通「信任区」仅对查杀扫描有效，**无法阻止该性能清理机制对曾经露过窗口的后台程序下手**。

---

## 二、方案一：免改配置的省心方案（推荐日常使用）

1. 在 Clash Mini 中开启 **「静默启动」**（弹窗内可点击 `⚡ 一键开启「静默启动」`，或进入「设置 → 基本设置」开启）。
2. 从 `v3.5.2` 起，只要启用「静默启动」且已有订阅配置，**无论开机自启、双击桌面/开始菜单图标启动，还是被误杀后重新点击图标启动**，Clash Mini 都会直接静默进入系统托盘而不创建或弹出主窗口（手动启动时仅弹出系统托盘气泡提示已在后台运行）。
3. **只要主窗口从未露面**，就不会被 360 性能引擎记入「开窗→关窗」观测名单，从而避免在高负载下被误杀。

> ⚠️ **重要提示**：采用此方案时，平时请尽量**不要左键点开主窗口**；一旦窗口露出过，再次关闭窗口回到轻量模式后仍可能在高 CPU 负载时被清理。若万一被误杀，重新点击桌面图标即可再次无感静默恢复托盘驻留。

## 三、方案二：一劳永逸根治方案（可随时自由开关窗口）

如果你希望随时点击托盘打开、关闭主窗口且彻底免疫 360 后台清理，需要将程序路径写入 360 性能引擎底层硬白名单文件。因 360 驱动自我保护机制会在正常系统下拒绝修改该文件，**必须在 Windows 安全模式下操作**：

1. **进入 Windows 安全模式**：
   按住键盘 `Shift` 键不放，点击 Windows「开始菜单 → 电源 → 重启」→ 进入蓝屏恢复菜单后依次选择「疑难解答 → 高级选项 → 启动设置 → 重启」→ 重启提示界面按数字键 `4`（启用安全模式）。
2. **编辑底层硬白名单文件**：
   在安全模式下用记事本打开以下文件（路径以实际 360 安装目录为准，默认如下）：
   ```text
   C:\Program Files (x86)\360\360Safe\netmon\whiteinternal.ini
   ```
   找到 `[paths]` 段落并在末尾追加以下两行内容并保存（索引号 `path1=`、`path2=` 请避开既有编号；若安装在其他磁盘路径，保留最后一级安装目录名 + 程序名后缀格式即可，例如 `D:\Tools\Clash Mini\clash-mini.exe` 同样写作 `Clash Mini\clash-mini.exe`）：
   ```ini
   path1=Clash Mini\clash-mini.exe
   path2=Clash Mini\mini-mihomo.exe
   ```
3. **正常重启电脑**：
   保存文件后正常重启进入 Windows，360 底层白名单即永久生效，此后无论是否在高 CPU 负载下开关主窗口均不会被误杀。

## 四、其他安全软件常规建议 & 技术边界

- **Windows Defender / 火绒等常规杀软**：如遇常规误报，将 Clash Mini 安装目录（默认 `C:\Program Files\Clash Mini\`）或 `clash-mini.exe`、`mini-mihomo.exe` 加入其排除项即可。
- **技术边界声明**：Clash Mini 仅使用 Tauri 标准 `RunEvent::ExitRequested`（`prevent_exit`）维持托盘后台驻留，绝不尝试在代码层绕过、破坏或强改第三方安全软件文件；上述安全模式配置完全由用户自主决定与执行。
